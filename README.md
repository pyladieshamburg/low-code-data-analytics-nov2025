# AI for Non-Data Scientists
### The Low-Code Path to Data-Driven Decisions  

This workshop introduces a practical, low-code approach to working with data, designed for people without a data science background. Using Julius.ai as an example platform, we explore how AI can help make data exploration, pattern discovery, visualization, and interpretation more accessible, so you can work with data confidently without deep technical skills.

## Repository Overview

This repository contains all materials we use in the workshop.  
They are written as clear, practical references during the session and for later use.

### [ds_workflow.md](./ds_workflow.md)  
This is the central reference.  
It walks through the full data workflow step by step and provides example prompts you can try directly in Julius.  
Use it as your guide for understanding how to move from a question to an insight.

### [Setup_Instructions.md](./Setup_Instructions.md)  
A short guide for getting started.  
It explains how to access Julius for the workshop, upload the provided files, and open the exercise notebook.

### [Exploration_guide.md](./Exploration_guide.md)  
A collection of example questions, small tasks, and explanations of key data concepts.  
It helps you explore the dataset on your own and practice asking clear, meaningful questions in Julius.

### [julius_ai_platform_overview.md](./julius_ai_platform_overview.md)  
An orientation guide to the Julius platform.  
It introduces the main areas of the interface — chats, notebooks, dashboards, files, data connectors, and templates — so you know where everything is and what each part is used for.
